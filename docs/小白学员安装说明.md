# Codex 历史修复工具：小白学员安装说明

适合完全不会打开 Terminal 的学员。

## 第一步：下载双击修复包

打开下载页面：

```text
https://github.com/Standed/codex-history-share/releases/latest
```

下载这个文件：

```text
Codex历史修复-mac.zip
```

下载后双击 zip 解压。

## 第二步：双击运行

打开解压出来的文件夹：

```text
Codex历史修复-mac
```

双击里面的文件：

```text
Codex历史修复.command
```

如果系统提示无法打开，可以右键这个文件，选择打开。

## 第三步：如果提示安装 Node.js

如果窗口提示没有安装 Node.js，工具会自动打开 Node.js 官网。

请安装 Node.js 24 LTS。

安装完成后，再双击一次：

```text
Codex历史修复.command
```

## 第四步：等待完成

看到窗口提示修复流程已经执行完成后，先完全退出 Codex Desktop：

```text
Command + Q
```

然后重新打开 Codex Desktop，看左侧历史是否回来了。

## 如果还是没回来

把这个日志文件发给老师或助教：

```text
~/.codex-history-share/double-click-install.log
```

也可以把下面两个文件一起发出来：

```text
~/.codex-history-share/watch.log
~/.codex-history-share/launchd.err.log
```
