# Codex 历史修复工具：小白学员安装说明

适合完全不会打开 Terminal 的学员。

## 第一步：下载安装包

打开下载页面：

```text
https://github.com/Standed/codex-history-share/releases/latest
```

下载这个文件：

```text
codex-history-repair-embedded-mac.pkg
```

不要优先下载 zip。zip 是备用方案，可能会被 macOS 安全提示拦住。

## 第二步：双击安装

双击下载好的安装包：

```text
codex-history-repair-embedded-mac.pkg
```

按安装器提示一路继续。

安装器会自动执行修复，不需要学员打开 Terminal。

## 第三步：如果提示安装 Node.js

内置版已经带了 Node.js，正常不需要学员额外安装 Node.js 或 Git。

## 第四步：重新打开 Codex

安装完成后，先完全退出 Codex Desktop：

```text
Command + Q
```

然后重新打开 Codex Desktop，看左侧历史是否回来了。

## 如果还是没回来

把这个日志文件发给老师或助教：

```text
/Users/Shared/codex-history-share/pkg-install.log
```

也可以把下面两个文件一起发出来：

```text
~/.codex-history-share/watch.log
~/.codex-history-share/launchd.err.log
```

## 老师注意

如果这个 pkg 没有 Apple Developer ID 签名和公证，部分电脑仍然可能出现安全提示。

真正适合大规模发给小白学员的版本，应该使用 Apple Developer ID Installer 证书签名，并通过 Apple notarization 公证。


## Windows 学员

打开下载页面：

```text
https://github.com/Standed/codex-history-share/releases/latest
```

下载这个文件：

```text
codex-history-repair-embedded-windows.zip
```

解压后双击：

```text
CodexHistoryRepair-Windows.cmd
```

如果 Windows SmartScreen 提示风险，点击“更多信息”，再点击“仍要运行”。

内置版已经带了 Node.js，正常不需要学员额外安装 Node.js 或 Git。

完成后，完全退出 Codex Desktop，再重新打开 Codex。

Windows 日志在：

```text
%USERPROFILE%\.codex-history-share\windows-install.log
%USERPROFILE%\.codex-history-share\doctor.txt
```

## 老师侧真正要彻底解决的问题

小白分发最难的不是脚本，而是系统安全机制：

- macOS 要用 Apple Developer ID Installer 签名并 notarize，否则可能被 Gatekeeper 拦。
- Windows 要做签名的 MSI/EXE，否则 SmartScreen 可能提示风险。
- Node.js 缺失无法完全绕过，除非后续把 Node runtime 一起打包进安装器。

当前最推荐使用 embedded 内置版，它已经带 Node.js 运行时，学员无需安装 Node.js 或 Git。
